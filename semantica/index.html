Concepto y Tipos de Bases de Datos

Bases de datos Relacionales (RDBMS)

Las bases de datos relacionales organizasn la información en tablas compuestas por filas (registros) y columnas (campos). Se basan en el modelo relacional y utilizan el lenguaje SQL (Structured Query Language) para realizar consultas y gestionar los datos de manera estructurada.

Ejemplos de sistemas gestores relacionalkes populares son MySQL, PostgreSQL y Oracle.

Bases de datos No Relacionales (NoSQL)

La Bases de datos NoSQL están diseñadas para gestionar grandes volúmenes de datos estructurados o semiestructurados. A diferencia de las relaciones, no requieren un esquema rígido y permiten escalabilidad horizontal.

Existen distintos tipos según el modelo de almacenamiento: orientadas a documentos, clave-valor, columnas o grafos. Un ejemplo representativo es MongoDB.

Estructura de una Base de Datos Relacional

Componentes fundamentales

Para definir la estructura dentro de un modelo relacional se empleam los siguiuentes:

  • Tablas (Entidades): Objetos principales sobre los cuales se almacena información estructurada.
  • Campos (Atributos): Columnas individuales que definen las propiedades o caracteristicas de cada entidad.
  • Registros(Tuplas): Filas individuales que representan cada elemento o instancia concreta guardada en la tabla.7
  • Claves Primarias(Primary Key):Campos cuyo valor es único o irrepetible para cada registro, garantizando su identificación.

Relaciones entre Tablas

Cardinalidades y Claves Foráneas

Las relaciones determinan cómo se vinvulan las entidades según las reglas de negocio del sistema:

  • Relación 1:1 (Uno a uno)
  • Relación 1:N (Uno a muchos)
  • Relación N:M (Muchos a muchos)

Clave Foránea (Foreing Key):Desempeña la función de vincular dos tablas, es decir relacionarlas.

Glosario de términos

  • SQL:Structured Query Language, es el lenguaje estándar para realizar consultas a una base de datos. Se caracteriza por ser un lenguaje declarativo
  • SGBD:Un Sistema Gestor de Bases de Datos (SGBD) es un software diseñado para almacenar, gestionar, recuperar y proteger datos de manera eficiente.
  • Normalización:La normalización en bases de datos es el proceso de organizar las tablas y sus relaciones para evitar datos duplicados, reducir errores y mejorar la integridad de la información.
